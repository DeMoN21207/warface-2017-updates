# Warface 2017 — обновления

Публичный канал выпусков локальной сборки.

Пакеты обновлений будут размещаться в [Releases](https://github.com/DeMoN21207/warface-2017-updates/releases). Скачать опубликованный публичный выпуск можно без доступа к закрытому репозиторию исходников.

Пока выпусков нет и автоматическое обновление лаунчера не подключено. `channel.json` явно отключён до появления проверенного пакета и реализации обновляющего клиента. `manifest.example.json` — только пример формата, его нельзя применять как обновление.

Сюда не публикуются база аккаунтов, логины и пароли, серверные ключи, сертификаты, персональные лаунчеры, настройки конкретного хозяина и журнал игры. Публикация каждого пакета проводится отдельно после проверки состава.

При текущем устройстве игры изменение одного файла внутри .pak может требовать загрузки всего изменённого .pak. Готовый полный клиент и обновления — разные пакеты.
