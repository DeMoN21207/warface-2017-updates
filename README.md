# Warface 2017 — обновления

Публичный канал [выпусков сборки](https://github.com/DeMoN21207/warface-2017-updates/releases). Доступ к исходникам и GitHub-токен не нужны.

Лаунчер 1.0.2 проверяет SHA256 всей опубликованной игры: пакеты, библиотеки, файлы карт, ролики и общие конфигурации. Отсутствующие и повреждённые файлы восстанавливаются; скачиваются только отличающиеся. Обрыв сети и отмена сохраняют загруженную часть для докачки. Изменённый `.pak` скачивается целиком, бинарных патчей нет.

Установленный лаунчер 1.0.1 сначала автоматически обновляет себя, затем после перезапуска проверяет игру. Для первого перехода с лаунчера без автообновления скачайте `WarfaceLauncher-Update-v1.0.2.zip`, закройте игру и старый лаунчер, замените EXE/config рядом с прежним лаунчером. Сохраните `server-profile.json`, `friend-profile.json` и `local-config`. Полный стартовый архив нужен один раз.

Проверка запускается при открытии, перед «Играть» и кнопкой «Проверить файлы». Счётчик показывает ход проверки хэшей. После скачивания помощник проверяет SHA256, сохраняет резервные копии и устанавливает изменения с перезапуском лаунчера. При открытой игре установка откладывается. При недоступном GitHub остаётся запуск установленной игры.

`channel.json` указывает на два каталога одного выпуска: `manifest.json` с EXE/config для совместимости со старым лаунчером и `client-manifest.json` с файлами игры. URL файлов принадлежат тому же выпуску. Канал переключается только после публикации и проверки всех ассетов. `manifest.example.json` — условный пример, рабочие каталоги находятся в Releases.

Аккаунты, пароли, сохранённый вход, настройки подключения, пользовательские профили, autoexec.cfg, серверные программы и модуль ботов в канал не входят. Они сохраняются при обновлении. Публичный клиентский набор центров сертификации cacert.pem включён; приватных ключей и серверных сертификатов нет. Резервные копии — `.updates`, ошибки установки — `logs/updater.log`.
