# Warface 2017 — обновления

Публичный канал выпусков локальной сборки.

Пакеты обновлений размещаются в [Releases](https://github.com/DeMoN21207/warface-2017-updates/releases). Скачать опубликованный публичный выпуск можно без доступа к закрытому репозиторию исходников и без GitHub-токена.

Лаунчер с автообновлением проверяет `channel.json` при открытии и перед запуском игры. При `enabled: true` он читает манифест указанного выпуска, скачивает только изменённые файлы, проверяет размер и SHA256, сохраняет резервные копии и перезапускается для установки. Кнопка «Обновить» повторяет проверку, «Отмена» прерывает загрузку. При открытой игре установка откладывается; при недоступности GitHub остаётся запуск установленной игры.

Для первого перехода скачайте `WarfaceLauncher-Update-v1.0.1.zip` из выпуска. Закройте игру и старый лаунчер, замените `WarfaceLauncher.exe` и `WarfaceLauncher.exe.config` рядом с прежним лаунчером. Сохраните существующие `server-profile.json` и `local-config`: в них ваше подключение и сохранённый вход. Полную игру заново скачивать не нужно. Последующие выпуски устанавливаются через новый лаунчер.

Начиная с 1.0.1 кнопка «Проверить файлы» сравнивает SHA256 всех файлов опубликованного каталога и восстанавливает повреждённые или отсутствующие. Обрыв сети и отмена сохраняют скачанную часть; следующая попытка продолжает загрузку при поддержке HTTP Range сервером. После докачки проверяется хэш всего файла. Если сервер не поддерживает Range, файл скачивается заново. Первый архив с полной игрой нужен один раз; обновления скачиваются по отдельным файлам.

Пока опубликованы только файлы лаунчера: полная проверка игровых пакетов потребует загрузки их каталога и самих файлов в канал. Один полный ZIP без доступных отдельных файлов этого не обеспечивает.

Первый выпуск обновляет только лаунчер. Формат поддерживает клиентские `.pak` и EXE/DLL в `Bin32Release`, с отдельным назначением `target: client`; папку игры берёт из настроек лаунчера. Сервер и модуль ботов через этот публичный канал не обновляются.

`manifest.example.json` содержит условные размер и хэш и не является настоящим пакетом. Рабочий `manifest.json` находится среди ассетов конкретного выпуска. URL каждого файла должен принадлежать этому же выпуску данного репозитория. Канал переключается только после загрузки и проверки ассетов. Резервные копии сохраняются в `.updates`, журнал ошибок — `logs/updater.log`.

Сюда не публикуются база аккаунтов, логины и пароли, серверные ключи, сертификаты, персональные лаунчеры, настройки конкретного хозяина и журнал игры. Публикация каждого пакета проводится отдельно после проверки состава.

При текущем устройстве игры изменение одного файла внутри .pak может требовать загрузки всего изменённого .pak. Готовый полный клиент и обновления — разные пакеты.
